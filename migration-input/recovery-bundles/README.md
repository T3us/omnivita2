# Bundles de recuperacao do navegador

Se algum navegador ainda tiver dados antigos em cache, voce e seus players podem exportar esses dados por aqui.

Coloque aqui os arquivos gerados pela pagina:

- `recuperar-dados.html`

Formato esperado dos arquivos:

- `omnivita-recovery-*.json`

O importador le esses bundles automaticamente junto com:

- `profiles.json`
- `characters.json`
- `companions.json`
- `auth-users.json`
